# Security Policy / セキュリティポリシー

Thank you for helping keep ArticleVideo Studio secure.

ArticleVideo Studioの安全性向上にご協力いただきありがとうございます。

## Supported Versions / サポート対象バージョン

| Version / バージョン | Status / 状態 |
|---|---|
| v0.1.0-preview.1 | Preview release / プレビュー版 |
| Older versions / 旧バージョン | Not officially supported / 正式サポート対象外 |

The project is currently in an early preview stage. Security fixes and updates are provided on a best-effort basis, without a guaranteed response or release schedule.

現在は初期プレビュー段階のため、セキュリティ修正や更新の提供時期は保証されません。

## Reporting a Vulnerability / 脆弱性の報告

Please do not disclose security vulnerabilities in public GitHub Issues or Discussions before they have been reviewed.

セキュリティ上の問題を発見した場合は、確認が完了するまで公開IssueやDiscussionsに詳細を投稿しないでください。

If private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** feature.

非公開の脆弱性報告機能が有効な場合は、GitHubの **Security → Report a vulnerability** を使用してください。

Repository:
https://github.com/tokumeiesu/ArticleVideoStudio

## Information to Include / 報告に含める情報

Please include, where possible:

- A description of the vulnerability / 脆弱性の概要
- Affected application version / 影響を受けるバージョン
- Operating system and device / OSと端末
- Steps to reproduce / 再現手順
- Potential security impact / 想定される影響
- Suggested mitigation, if available / 対策案（任意）

Please avoid sharing personal data, passwords, API keys, signing keys, or private project files.

## Responsible Disclosure / 責任ある情報公開

We ask researchers to allow reasonable time for investigation and remediation before publicly disclosing vulnerability details.

脆弱性の詳細を公開する前に、調査と修正のための合理的な期間を設けていただくようお願いします。

## Scope / 対象範囲

Security reports may concern:

- Application and project file handling / アプリ・プロジェクトファイルの処理
- Media import and parsing / 動画・音声・画像の読み込み
- Local AI integration / ローカルAI連携
- Network communication / ネットワーク通信
- Plugin and external tool integration / 外部ツール連携
- Installation and update mechanisms / インストール・更新処理

The inclusion of a category does not imply that all related functionality is implemented in the current preview release.

## Languages / 対応言語

Security reports are welcome in Japanese or English.

日本語・英語のどちらでも報告できます。
