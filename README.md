# ArticleVideoStudio
Cross-platform AI-powered video editor for collaborative human-AI creation.
ArticleVideo Studio

AI-assisted cross-platform video editing

ArticleVideo Studioは、人間とAIが共通のタイムラインを操作し、GUIと自然言語によって動画を共同制作することを目指した動画編集プロジェクトです。

ArticleVideo Studio is a cross-platform video editing project designed for human-AI collaboration through a shared timeline, graphical tools, and natural language instructions.

Project Vision / 開発理念

人間とAIが同じ編集環境を共有し、それぞれの得意な操作を組み合わせて映像を制作することを目指しています。

The goal is to enable humans and AI to collaborate within a unified video editing environment.

Development Goals / 開発目標

- Human-AI collaborative editing / 人間とAIの共同編集
- Local AI integration / ローカルAI連携
- Timeline-based editing / タイムライン編集
- Vector graphics and animation / ベクターとアニメーション
- Natural language editing / 自然言語による編集
- Cross-platform interface / OS間で統一されたUI
- Mouse, touch and pen support / マウス・タッチ・ペン対応
- Extensible workspace architecture / 拡張可能なワークスペース

These are project goals, not a guarantee that every feature is available in the current preview.

上記には開発予定の機能も含まれています。

Installation / インストール

Android

Download the APK and install it on a compatible ARM64 Android device.

APKをダウンロードし、対応するAndroid端末にインストールしてください。

Windows

Download and run the Windows x64 installer.

EXEインストーラーを実行してください。現在のインストーラーにはコード署名がありません。

Linux

Download the DEB package and install it using:

sudo apt install ./ArticleVideoStudio-linux-amd64.deb

Launch with:

articlevideo-studio
