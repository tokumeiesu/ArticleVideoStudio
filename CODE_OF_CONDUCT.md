# Code of Conduct / コミュニティ行動規範

## Our Commitment / 基本方針

ArticleVideo Studioは、国籍、言語、経験、技術力、年齢、性別、障害の有無などにかかわらず、誰もが安心して参加できるコミュニティを目指します。

ArticleVideo Studio aims to provide a welcoming, respectful, and inclusive community for everyone, regardless of background, identity, or technical experience.

## Expected Behavior / 推奨される行動

参加者には以下の行動を推奨します。

- 他の参加者を尊重し、建設的に議論する
- 技術的な意見の違いを認める
- 初心者や新しい参加者を歓迎する
- 不具合報告や改善提案に誠実に対応する
- 他者の著作権、プライバシー、成果物を尊重する
- 日本語・英語のどちらの利用者にも配慮する

We encourage respectful communication, constructive feedback, collaboration, and recognition of others' contributions.

## Unacceptable Behavior / 禁止される行動

以下の行為は認められません。

- 嫌がらせ、差別、脅迫、個人攻撃
- 他者の個人情報を許可なく公開する行為
- 意図的な荒らしやスパム
- 他者の著作物を無断で自分の成果物として公開する行為
- コミュニティ活動を継続的に妨害する行為

Harassment, discrimination, threats, personal attacks, spam, privacy violations, and deliberate disruption are not acceptable.

## Scope / 適用範囲

This Code of Conduct applies to project-managed community spaces, including:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- Code reviews
- Other official ArticleVideo Studio community spaces

本規範は、ArticleVideo Studioが管理する公式コミュニティに適用されます。

## Enforcement / 違反への対応

Project maintainers may take appropriate action when this Code of Conduct is violated.

Depending on the situation, actions may include:

1. A request to change inappropriate behavior
2. A formal warning
3. Removal or moderation of inappropriate content
4. Temporary restrictions on participation
5. Permanent restrictions for serious or repeated violations

プロジェクト管理者は、違反内容に応じて注意、投稿の削除、一時的または恒久的な参加制限などを行う場合があります。

## Reporting / 違反の報告

If you encounter a Code of Conduct violation, please contact the project maintainers through an appropriate private communication channel, where available.

行動規範違反を報告する場合は、利用可能な非公開の連絡手段でプロジェクト管理者に連絡してください。

Do not include private personal information in public Issues or Discussions.

**Note:** GitHub's private vulnerability reporting feature is intended for security vulnerabilities, not general community conduct complaints.

## Languages / 対応言語

Japanese and English are welcome.

日本語・英語のどちらでも参加できます。

## Updates / 改訂

This Code of Conduct may be updated as the community grows.

本規範は、コミュニティの成長に合わせて改訂される場合があります。
